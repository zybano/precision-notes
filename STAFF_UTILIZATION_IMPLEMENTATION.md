# Staff Utilization Tracking Implementation

## Overview
This implementation adds comprehensive staff utilization tracking to Documedly, allowing organizations to monitor credits used and documentations generated by each staff member.

## Database Schema

### New Tables

#### 1. `staff_utilization`
Stores daily aggregated metrics for each staff member:
- **Purpose**: Daily summary of staff activity
- **Key Fields**:
  - `user_id`: Reference to organization user
  - `organization_id`: Reference to organization
  - `date`: Date of activity (unique per user per day)
  - `credits_used`: Total credits consumed
  - `documents_generated`: Number of documents created
  - `transcriptions_completed`: Number of transcriptions processed
  - `metadata`: Additional tracking data (JSONB)

#### 2. `staff_activity_log`
Stores detailed activity records for each request:
- **Purpose**: Detailed audit trail of all staff activities
- **Key Fields**:
  - `user_id`: Reference to organization user
  - `organization_id`: Reference to organization
  - `activity_type`: Type of activity ('transcription', 'document_generation', 'combined_request')
  - `credits_used`: Credits consumed for this activity
  - `request_id`: Unique request identifier
  - `document_format`: Format of generated document
  - `transcription_provider`: Provider used (e.g., 'assemblyai')
  - `model_used`: AI model used (e.g., 'gpt-4-turbo')
  - `processing_time_ms`: Time taken to process
  - `metadata`: Additional activity metadata (JSONB)

## Database Functions

### 1. `record_staff_activity`
Records a staff activity and updates daily utilization metrics.

**Parameters**:
- `p_user_id` (uuid): User ID
- `p_organization_id` (uuid): Organization ID
- `p_activity_type` (text): Activity type
- `p_credits_used` (integer): Credits consumed
- `p_request_id` (text, optional): Request ID
- `p_document_format` (text, optional): Document format
- `p_transcription_provider` (text, optional): Transcription provider
- `p_model_used` (text, optional): AI model used
- `p_processing_time_ms` (integer, optional): Processing time
- `p_metadata` (jsonb, optional): Additional metadata

**Returns**: Success status and activity log ID

### 2. `get_staff_utilization`
Retrieves daily utilization data for a specific staff member.

**Parameters**:
- `p_user_id` (uuid): User ID
- `p_start_date` (date, optional): Start date filter
- `p_end_date` (date, optional): End date filter

**Returns**: Table of daily utilization records

### 3. `get_organization_staff_utilization`
Retrieves aggregated utilization for all staff in an organization.

**Parameters**:
- `p_organization_id` (uuid): Organization ID
- `p_start_date` (date, optional): Start date filter
- `p_end_date` (date, optional): End date filter

**Returns**: Table with per-staff totals and user information

### 4. `get_staff_activity_details`
Retrieves detailed activity log for a specific staff member.

**Parameters**:
- `p_user_id` (uuid): User ID
- `p_start_date` (timestamptz, optional): Start timestamp filter
- `p_end_date` (timestamptz, optional): End timestamp filter
- `p_limit` (integer, optional): Maximum records to return (default: 100)

**Returns**: Table of activity log entries

## API Endpoints

### 1. `GET /organization-auth/staff/utilization`
Get staff utilization summary for a specific user or current user.

**Query Parameters**:
- `user_id` (optional): User ID to query (requires admin for other users)
- `start_date` (optional): Start date (YYYY-MM-DD)
- `end_date` (optional): End date (YYYY-MM-DD)

**Authentication**: Bearer token required

**Response**:
```json
{
  "user_id": "uuid",
  "daily_utilization": [
    {
      "date": "2025-11-29",
      "credits_used": 15,
      "documents_generated": 5,
      "transcriptions_completed": 3,
      "metadata": {}
    }
  ],
  "totals": {
    "total_credits": 15,
    "total_documents": 5,
    "total_transcriptions": 3
  }
}
```

### 2. `GET /organization-auth/staff/activity`
Get detailed activity log for a specific user or current user.

**Query Parameters**:
- `user_id` (optional): User ID to query (requires admin for other users)
- `start_date` (optional): Start date (ISO 8601)
- `end_date` (optional): End date (ISO 8601)
- `limit` (optional): Maximum records (default: 100, max: 1000)

**Authentication**: Bearer token required

**Response**:
```json
{
  "user_id": "uuid",
  "activities": [
    {
      "id": "uuid",
      "activity_type": "combined_request",
      "credits_used": 5,
      "request_id": "req_123",
      "document_format": "soap",
      "transcription_provider": "assemblyai",
      "model_used": "gpt-4-turbo",

      "metadata": {
        "language_code": "en_us",
        "include_summary": true
      }

```

Get organization-wide staff utilization summary (admin only).

**Query Parameters**:

**Authentication**: Bearer token required (admin only)

## Edge Function Integration

### Automatic Tracking in B2B Functions

The `b2b-combined-request` function now automatically tracks staff activity when a session token is provided in the Authorization header.

**Tracking Mechanism**:
1. Extract session token from Authorization header
2. Validate session and get user_id
3. Verify user belongs to the organization
4. Record activity with detailed metadata

**Tracked Metadata**:
- Language code
- Summary inclusion
- Speech model used (nano vs standard)
- Audio file size
- Processing time
- Model used
- Document format

### Shared Utility (`_shared/staffActivityTracker.ts`)

Two utility functions for tracking staff activity:

#### `recordStaffActivity(supabase, params)`
Records a staff activity in the database.

#### `getUserIdFromSessionToken(supabase, sessionToken)`
Extracts user_id and organization_id from a session token.

## Frontend Integration

### New Types (`src/types/staffUtilization.ts`)

Type definitions for all staff utilization data structures:
- `StaffUtilizationDaily`
- `StaffUtilizationTotals`
- `StaffUtilizationResponse`
- `StaffActivity`
- `StaffActivityLogResponse`
- `OrganizationStaffUtilization`
- `OrganizationStaffUtilizationTotals`
- `OrganizationStaffUtilizationResponse`

### API Functions (`src/services/orgAuthApi.ts`)

Three new functions added:

#### `fetchStaffUtilization(token, userId?, startDate?, endDate?)`
Fetch utilization summary for a staff member.

#### `fetchStaffActivityLog(token, userId?, startDate?, endDate?, limit?)`
Fetch detailed activity log for a staff member.

#### `fetchOrganizationStaffUtilization(token, startDate?, endDate?)`
Fetch organization-wide staff utilization (admin only).

## Access Control

### Staff (role: 'staff')
- Can view their own utilization data
- Can view their own activity log
- Cannot view other staff members' data

### Admin (role: 'admin')
- Can view all staff utilization data
- Can view all staff activity logs
- Can view organization-wide statistics
- Full access to all utilization endpoints

## Usage Examples

### Track Staff Activity (Backend)
```typescript
import { recordStaffActivity, getUserIdFromSessionToken } from "../_shared/staffActivityTracker.ts";

// In edge function
const authHeader = req.headers.get("authorization");
if (authHeader?.startsWith("Bearer ")) {
  const sessionToken = authHeader.replace("Bearer ", "").trim();
  const { userId, organizationId } = await getUserIdFromSessionToken(
    supabase,
    sessionToken
  );

  if (userId && organizationId) {
    await recordStaffActivity(supabase, {
      userId,
      organizationId,
      activityType: 'combined_request',
      creditsUsed: 5,
      requestId: 'req_123',
      documentFormat: 'soap',
      transcriptionProvider: 'assemblyai',
      modelUsed: 'gpt-4-turbo',
      processingTimeMs: 3500,
      metadata: {
        language_code: 'en_us',
        include_summary: true
      }
    });
  }
}
```

### Fetch Staff Utilization (Frontend)
```typescript
import { fetchStaffUtilization, fetchOrganizationStaffUtilization } from '@/services/orgAuthApi';

// Get current user's utilization
const userUtilization = await fetchStaffUtilization(token);

// Get specific staff member's utilization (admin only)
const staffUtilization = await fetchStaffUtilization(token, staffUserId);

// Get organization-wide utilization (admin only)
const orgUtilization = await fetchOrganizationStaffUtilization(
  token,
  '2025-11-01', // start date
  '2025-11-30'  // end date
);
```
